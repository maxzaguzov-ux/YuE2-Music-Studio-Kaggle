# 🎵 YuE2 Music Studio - Kaggle Notebook

AI-powered text-to-music generation using YuE2 model with interactive Gradio interface.

## 🚀 Quick Start

Click the button below to open this notebook directly in Kaggle:

[![Open in Kaggle]([https://kaggle.com/static/images/open-in-kaggle.svg)](https://www.kaggle.com/kernels/welcome?src=https://github.com/maxzaguzov-ux/YuE2-Music-Studio-Kaggle/blob/main/Yue2_text2music_kaggle.ipynb](https://www.kaggle.com/kernels/welcome?src=https://github.com/maxzaguzov-ux/YuE2-Music-Studio/blob/main/Yue2_text2music_kaggle.ipynb))

## 📝 Features

- 🎼 **5 Genre Presets**: Indie Pop, Synthwave, Lo-Fi, Cinematic, Alt Rock
- ✍️ **Custom Lyrics**: Support for [Verse], [Chorus], [Bridge], [Outro] structure
- ⚙️ **Advanced Controls**: Sampler, scheduler, steps, seed, ABC planning
- 🎧 **Real-time Progress**: Live progress bar during generation
- 📥 **Easy Download**: Built-in audio player and batch download

## 🛠️ Requirements

- **GPU**: T4 x2 or P100 (recommended)
- **Internet**: Enabled (for model download)
- **Storage**: ~10 GB free space

## 📖 How to Use

1. Click "Open in Kaggle" button above
2. Enable GPU: Settings → Accelerator → GPU T4 x2
3. Enable Internet: Settings → Internet → ON
4. Run cells 1-3 to setup environment
5. Run cell 4 to launch Gradio interface
6. Click the public link to open the studio
7. Configure your music and generate!

## 🎨 Interface Preview

The Gradio interface provides:
- Style & Lyrics configuration
- Generation settings (sampler, steps, seed)
- Real-time progress monitoring
- Built-in audio player
